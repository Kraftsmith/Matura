# HTML-макет лендинга MaturaEnglish

Готовый адаптивный прототип главной страницы. Дата: 11 ноября 2026 года.

## Как открыть

Откройте `index.html` двойным щелчком в Chrome, Edge или другом современном браузере. Сборка, сервер и установка зависимостей для просмотра не нужны. При переносе макета сохраняйте рядом файлы CSS, JavaScript и папку `assets`.

## Что реализовано

- Первый экран с основным призывом к регистрации и интерактивным примером задания.
- Мини-тест из трех вопросов: проверка ответа, объяснение, переход к следующему вопросу и повтор.
- Бесплатная тема Człowiek и ссылки на разделы действующего сайта.
- Три шага подготовки, примеры грамматики и переворачиваемая словарная карточка.
- Каталог из 14 тем с раскрытием дополнительных карточек.
- Информация для родителей и учителей.
- Тарифы, FAQ, заключительный призыв к действию и подвал.
- Мобильное меню, клавиатурное управление интерактивными элементами и поддержка reduced motion.

## Структура файлов

| Файл | Назначение |
| --- | --- |
| `index.html` | Структура страницы и польские тексты |
| `landing.css` | Цвета, типографика, компоненты и адаптивная верстка |
| `landing.js` | Мини-тест, карточка, каталог и мобильное меню |
| `assets/` | Локальные шрифты Figtree, иллюстрация и favicon |
| `preview/` | Скриншоты страницы и отчет проверок |
| `tools/check-landing.mjs` | Автоматическая проверка в headless Chrome |

## Дизайн и содержание

Использованы существующая дизайн-система, бирюзовый основной цвет, лавандовые поверхности, Figtree и иллюстрация из проекта. Приоритет отдан первому экрану, бесплатному входу в продукт и демонстрации учебного задания.

Цены взяты из актуального документа `../Spec - Subskrypcje i cennik.md`: Uczeń 20 zł в месяц, Rodzic и Nauczyciel по 30 zł в месяц. Платные предложения помечены как планируемые. Бесплатный доступ показан для одной полной темы Człowiek.

Регистрация и ссылки на учебные разделы ведут на `https://maturaenglish.pl`. Перед переносом в production необходимо подтвердить доступность целевых маршрутов и согласовать окончательные цены. В макете нет оплаты, сохранения прогресса или серверной регистрации. Ответы мини-теста существуют только в текущем сеансе страницы.

## Проверки

Автоматическая проверка прошла на ширинах 320, 390, 500, 768 и 1440 px. Горизонтального переполнения, ошибок JavaScript и ошибок загрузки локальных ресурсов не обнаружено. Проверены неправильный и правильный ответы, все три вопроса, повтор теста, карточка мышью и клавиатурой, раскрытие 14 тем, FAQ, мобильное меню, Escape и возврат фокуса. Проверены внутренние якоря и отключение плавной прокрутки при reduced motion.

Отчет: `preview/checks.json`. Скриншоты: `preview/landing-1440.png`, `preview/landing-390.png`, а также отдельные изображения первых экранов. Макет просмотрен визуально на desktop и mobile. Это проверка прототипа в Chrome, не полный аудит доступности и не кроссбраузерная сертификация.

Для повторного автоматического прогона нужны Node.js, Chrome и пакет `puppeteer-core`. Скрипт принимает `PUPPETEER_MODULE` (путь к установленному пакету) и `CHROME_PATH` (путь к браузеру), если стандартные пути отличаются. Команда из корня проекта:

```powershell
node 'Spec\Design\tools\check-landing.mjs'
```

## Статус

Это локальный HTML-прототип для просмотра и дальнейшего переноса в приложение. Исходники production-сайта не изменены, публикация не выполнялась.
