## 2. Как устроено технически

- **Tailwind CSS 4** в обоих проектах (`@tailwindcss/vite`). Токены объявлены в блоке `@theme` в `app/src/tokens.css` и становятся классами: `bg-primary`, `text-ink-2`, `border-line`, `rounded-lg`, `shadow-card` и т. д. Конфига `tailwind.config.*` нет.
- **Один файл токенов на сайт и приложение.** Сайт импортирует `../../../app/src/tokens.css` в `site/src/styles/global.css` и объявляет `@source "../../../app/src"`, потому что рендерит компоненты приложения (острова `site/src/islands/*` оборачивают `VocabularyView`, `LanguageUseIsland` и другие).
- **Сайт переопределяет один токен:** `--color-ink-3: #6B7380` (в приложении `#8B929C`). Причина: на сайте больше мелкого текста, и приглушённый серый приложения не проходит AA на сером фоне.
- **Утилиты** объявлены через `@utility`: `card`, `tile`, `heading-tight` (общие), `display`, `lead`, `section-title`, `wrap` (только сайт).
- **Шрифт** самохостится: четыре variable-файла (latin, latin-ext, italic × 2), `font-display: swap`, `unicode-range`. Сайт делает `<link rel="preload">` на два прямых файла. Google Fonts не используется (скорость и RODO). Файлы лежат в `app/public/fonts`, сайт копирует их в корень сборки (`/fonts/`), поэтому приложение под `/app/` их находит. При `npm run dev` одного приложения браузер падает на системный шрифт: это ожидаемо.
- **База текста:** приложение `16px / 24px`, сайт `17px / 1.6`. В обоих: `body` = `bg-page text-ink antialiased`, `h1, h2` = `font-medium heading-tight` + `text-wrap: balance`, `h3, h4` = `font-semibold`.
- **Сайт** отключает анимации при `prefers-reduced-motion: reduce` и включает `scroll-behavior: smooth`.
- **Иконки:** `lucide-react` везде (сайт и приложение), одна копия через alias в `site/astro.config.mjs`.

### 3.2 Типографика

- **Гарнитура:** `--font-sans: "Figtree", "Segoe UI", Arial, sans-serif`. Variable 300–900, используемые веса: 400 (текст), 500 (заголовки страниц, `display`, `section-title`), 600 (заголовки секций и карточек, кнопки, активная вкладка, метки полей), 700 (только `KeyTag` и остатки на сайте, см. §12). Ничего жирнее 700.
- **Моноширинный** только в `<code>` прозы сайта (`font-mono text-[0.9em]`), в UI не используется.
- **Трекинг:** `heading-tight` = `-0.01em` на заголовках страниц и секций. Вордмарк навбара `tracking-tight`. Заглавные с трекингом не должны использоваться (остатки см. §12).

Одна тень: `--shadow-card: 0 1px 2px rgba(30,34,40,.04), 0 4px 16px rgba(30,34,40,.06)` (класс `shadow-card`). ### 3.5 Две поверхности

| Утилита | Что | Где |
| :-- | :-- | :-- |
| `card` | `rounded-2xl bg-surface shadow-card`: белая панель с мягкой тенью на **серой** странице | Приложение: каждый контентный блок. Сайт: все внутренние страницы (`/tematy`, `/cennik`, страницы тем, FAQ, тарифы), продуктовые карточки лендинга |

Правило: на серой странице карточки, на белой секции плитки. `Card` принимает `tone="card" | "tile"` и `padding="none" | "md" (p-5) | "lg" (p-6 sm:p-8)`.

### 3.6 Отступы и сетка

- Сайт: контейнер `wrap` = `mx-auto w-full max-w-[1120px] px-4 sm:px-6`. Секции лендинга `py-20` / `pb-20`, крупные блоки внутри `px-6 py-12 sm:px-10 lg:px-14 lg:py-16`. Сетки плиток `gap-4`, продуктовых карточек `gap-5`, карточек тем `gap-3`. Текстовые страницы `max-w-3xl`.
- Приложение: `main` = `p-4 sm:p-6 lg:p-8`; `ModuleHeader` выходит за эти поля отрицательными отступами, чтобы полоса `bg-hero` шла во всю ширину. Витрина дизайн-системы `max-w-5xl`, разделы `gap-12`, внутри `gap-5`.
- Внутренние отступы карточек: `p-5` (список, статистика), `p-6` (заголовок темы на сайте, тарифы), `p-7` (плитки лендинга), `p-8 sm:p-10` (большая плитка).
- Фокус: везде `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-primary`; внутри строк списка и вкладок `outline-offset-[-2px]`; в тёмном сайдбаре `outline-white`.

## 4. Примитивы UI (`app/src/components/ui`)

Всё новое строится из них; сырые `rounded-2xl border border-line bg-surface` в коде больше не встречаются (проверено grep, 0 вхождений).

### Button (`Button.tsx`, `buttonClass.ts`)

База: `inline-flex items-center justify-center gap-2 rounded-lg border font-semibold whitespace-nowrap transition-colors duration-150`, disabled = `border-chip bg-chip text-ink-3`. `buttonClass(variant, size)` отдаёт строку для ссылок и `<label>`.

| Вариант | Вид |
| :-- | :-- |
| `primary` | `bg-primary text-white`, hover `primary-hover`. Один на экран |
| `secondary` | `bg-primary-tint text-primary`, без обводки, hover `primary-tint-2` (кнопка «Zamów teraz» home.pl в нашем акценте) |
| `ghost` | прозрачная, `text-primary`, hover `bg-primary-tint` |

| Размер | Метрики |
| :-- | :-- |
| `md` | `text-base leading-6 px-6 py-[11px]` (высота 48) |
| `sm` | `text-sm leading-5 px-3 py-2` (высота 38) |
| `icon` | `p-2`, только с `aria-label` |

Проп `full` растягивает на ширину. Пара оценки фишки: «Powtórz» secondary + «Umiem» primary вместо красно-зелёной пары. Иконки только рядом с текстом, 16 px (`h-4 w-4`).

### Chip, KeyTag (`Chip.tsx`)

`Chip`: пилюля `rounded-full`, `md` = `text-sm px-3 py-1`, `sm` = `text-xs px-2 py-0.5`. Тона: `neutral` (`bg-chip text-ink`, вес 400) по умолчанию; `primary`, `success`, `warning`, `error` (тонированный фон + цветной текст, вес 600) только для реального статуса. `KeyTag`: слово-ключ трансформации, `rounded border border-ink bg-surface text-sm font-bold tracking-wider`, единственное место с весом 700 и трекингом в приложении.

### TextField, TextArea, InlineInput (`TextField.tsx`)

`fieldClass`: `rounded bg-surface px-3 py-[9px] text-base border border-ink-2`, hover `border-ink`, focus `border-primary` + outline, disabled `border-line bg-hero text-ink-3`, `aria-invalid` = `border-error`. Оболочка: метка над полем `text-base font-semibold`, справа опциональный `trailing` (`text-sm text-ink-2`, например счётчик слов), под полем `hint` (ink-2) или `error` (error). `leadingIcon` 18 px слева. `InlineInput`: поле внутри предложения, `min-w-[180px] rounded border px-3 py-1.5 font-semibold`, состояния `idle | correct | wrong` меняют обводку, фон и цвет текста на success/error.

### Tabs (`Tabs.tsx`)

`role="tablist"`, горизонтальный скролл без полосы, нижняя линия `border-line`. Вкладка: `px-4 py-3 text-base`, активная = `border-b-[3px] border-primary font-semibold text-ink`, неактивная = прозрачная граница, hover `text-primary`. Счётчик через `count` серым (`font-normal text-ink-2`). Только текстовые вкладки, без icon-only.

### OptionCard (`OptionCard.tsx`)

Вариант ответа A/B/C/D: `role="radio"`, `rounded-lg border px-4 py-3`, слева круг 24 px с рамкой 2 px. Состояния: `idle` (`border-line`, hover `border-ink-2`), `selected` (`border-primary ring-1 ring-inset ring-primary`, точка внутри), `correct` (`border-success bg-success-tint`, галочка на зелёном круге), `wrong` (`border-error bg-error-tint`, крест). Текст не меняет вес и не зачёркивается; объяснение `feedback` появляется под карточкой `pl-9 text-sm text-ink-2`.

### Card, ListRow, SectionTitle (`Card.tsx`)

`Card` см. §3.5. `ListRow`: строка списка-кнопка `border-b border-line-soft border-l-4 px-3 py-3`, активная = `border-l-primary bg-primary-tint font-semibold`, иначе hover `bg-hero`. `SectionTitle`: `h2 text-2xl font-semibold` + описание `text-sm text-ink-2 max-w-[72ch]` + слот `action` справа.

### Callout (`Callout.tsx`)

`role="note"`, `rounded-lg border border-line border-l-4 bg-surface px-5 py-4`, цвет левой полосы и иконки lucide 20 px по тону `info` (primary), `warning`, `success`, `error`. Заголовок `font-semibold`, тело `text-base`.

### Meter, IconBadge, StatTile (`Meter.tsx`)

`Meter`: `role="progressbar"`, трек `bg-line-soft rounded-full`, `sm` = 8 px, `md` = 12 px, заливка одним цветом (`primary | success | warning | neutral`), `transition-[width] duration-300`, без градиентов. `IconBadge`: круг 44 px с пастельным градиентом и белой иконкой. `StatTile`: `card p-5`, подпись `text-lg font-semibold`, число `text-4xl font-semibold tabular-nums`, под ним `hint` (обычно `Meter`).

### Dialog (`Dialog.tsx`)

Оверлей `bg-ink/50`, на телефоне во весь экран, с `sm` карточка `rounded-2xl border border-line`, `max-w-[560px]` или `lg` = 720. Шапка `px-5 py-4 border-b border-line-soft` с `h2 text-xl font-semibold` и кнопкой X 36 px; тело `grid gap-4 overflow-y-auto`; футер с кнопками. Escape и клик по фону закрывают.

### Drawer (`Drawer.tsx`)

Панель у правого края для справки и деталей, которые читают рядом с работой: страница остаётся видна под оверлеем `bg-ink/30`. На телефоне во всю ширину, с `sm` ширина 560 px, высота во весь экран, `bg-surface shadow-card`, без скруглений. Шапка как у `Dialog` (`h2 text-xl font-semibold`, под ним необязательная строка `description` `text-sm text-ink-2`, кнопка X 36 px); необязательный `toolbar` (поиск, фильтры) закреплён под шапкой; тело `overflow-y-auto overscroll-contain px-5`. Въезжает справа за 200 ms (`motion-safe:animate-drawer-in`, токен `--animate-drawer-in`). Escape и клик по фону закрывают; фокус переходит в панель и возвращается на открывший её элемент. Внутри панели белый фон, поэтому содержимое не кладут в `card`: список с разделителями `divide-line-soft`.

Когда что: `Dialog` для короткого действия, которое надо завершить или отменить (форма, подтверждение); `Drawer` для материала, с которым сверяются, не уходя со страницы.

### Toast (`Toast.tsx`)

`role="status"`, снизу по центру, `rounded-lg bg-ink text-white text-sm px-4 py-3 shadow-lg`, одно действие подчёркнутым текстом.

### Вне папки `ui`, но часть системы

- `Avatar` (`GrammarStatusChip.tsx`): круг с инициалами `bg-primary-tint text-primary font-semibold`, размеры 28 / 36 / 48 px. Единственный «аватар» в продукте.

- `SaveStatus`, `SelectionCardBar`, `LessonBar`: панели на тех же токенах.

| Ситуация | Как показываем |
| :-- | :-- |
| Правильный ответ | `success` + `success-tint`: `OptionCard` зелёная рамка и фон, галочка; `InlineInput` зелёная; чип «opanowane» |
| Неправильный | `error` + `error-tint`: красная рамка/фон, крест; текст ошибки под полем; таймер ≤ 10 с |
| Ловушка CKE, предупреждение | `Callout tone="warning"` с AlertTriangle; на сайте плашка `bg-warning-tint text-warning` |
| Информация, подсказка | `Callout tone="info"` (полоса primary, иконка Info) |
| Выбрано, активно | `primary`: подчёркивание вкладки, левый маркер строки 4 px, `bg-primary-tint` фон строки, `ring-primary` у варианта |
| Нейтральные метки | `Chip` без тона (уровень B1+/B2, часть речи, тема) |
| Disabled | `bg-chip text-ink-3` (кнопка), `bg-hero border-line text-ink-3` (поле) |
| Hover | кнопки: сдвиг на соседний токен (`primary-hover`, `primary-tint-2`); строки и пункты меню: `bg-hero`; в сайдбаре `bg-side-2` |
| Загрузка | отдельного скелетона нет; `animate-pulse` под запретом (в коде 1 вхождение, см. §12) |
| Пустое состояние | текст `text-ink-2` в карточке, без иллюстраций |
| Успех, завершение | `Callout tone="success"`, тост, конфетти после серии фишек и теста |

## 9. Движение

- `transition-colors duration-150` на кнопках и строках; `transition` на карточках тем (подъём 2 px + тень).
- `Meter`: `transition-[width] duration-300`; таймер `duration-1000 ease-linear`.
- Фишка: переворот 500 ms (`transition-transform`), витрина описывает 0.6 s `cubic-bezier(0.4,0,0.2,1)`.
- Сайдбар на телефоне: `translate-x` 300 ms `ease-in-out`.
- `Drawer`: въезд справа 200 ms `ease-out` (`animate-drawer-in`), только при `motion-safe`.
- FAQ: поворот плюса на 45°.
- Конфетти `canvas-confetti` после серии фишек и теста.
- Сайт глушит всё при `prefers-reduced-motion`. Приложение пока нет.
- Запрещено: `animate-pulse`, мигания, параллакс, градиентные анимации.

## 10. Доступность

- Фокус видимый везде: `outline-2 outline-primary offset 2` (внутри строк и вкладок offset −2, в сайдбаре белый).
- Роли: `tablist/tab` (`Tabs`), `radio` + `aria-checked` (`OptionCard`), `progressbar` с `aria-valuenow` (`Meter`), `dialog aria-modal aria-labelledby` (`Dialog`, `Drawer`), `status` (`Toast`, `GuestBar`), `note` (`Callout`), `menu/menuitem` (меню пользователя), `aria-current="page"` на активных строках и ссылках.
- Skip-link на сайте, `lang="pl"`, подписи к картинкам, `aria-label` на иконочных кнопках.
- Минимальный размер текста 12 px, вторичный 14 px в `ink-2`. На сайте `ink-3` затемнён до `#6B7380` ради AA.
- Контраст primary `#17818F` на белом ≈ 4.6:1 (AA для обычного текста). Текст на `primary` только белый.
- Lighthouse на 09.11.2026: 99–100 performance и SEO, 95–96 accessibility (мобильный профиль).

## 11. Правила применения (чеклист для новых экранов)

1. Новый UI собирается из примитивов `app/src/components/ui` и токенов `@theme`. Никаких сырых цветов Tailwind (`slate-*`, `indigo-*` и т. п.; в коде 0 вхождений), никаких hex в классах, кроме `IconBadge`.
2. Поверхность: `card` на серой странице, `tile` на белой секции. Не `rounded-2xl border border-line bg-surface`.
3. Один `primary` на экран; остальное `secondary` или `ghost`. Secondary = тонированная подложка без обводки.
4. Семантический цвет только для результата ученика. Декор, иерархия и акценты только через `primary`, `ink-*` и поверхности.
5. Заголовки крупные и лёгкие: страница 500, секция/карточка 600, трекинг −0.01 em. Не `font-bold` на заголовках, не 800–900.
6. Без заглавных с трекингом для надзаголовков и меток; вместо них `text-sm text-ink-2` или `Chip`.
7. Двухцветный заголовок только на публичном сайте, один раз на экран.
8. Лавандовая полоса `band` не больше одной секции на страницу.
9. Иконки lucide 16–20 px в цвете текста, всегда рядом с подписью; вкладки только текстовые.
10. Радиусы: 4 px поля и `KeyTag`, 8 px кнопки и варианты, 16 px карточки и плитки, 28 px крупные контейнерные блоки лендинга, `full` для чипов.
11. Тень одна, `shadow-card`; обводок у карточек нет (исключения: выделенный тариф `border-2 border-primary`, `AccessWall` `border-primary/30`, `Callout`, `Dialog`).
12. Фокус `focus-visible:outline-2 outline-primary`, роли ARIA как в §10.
13. Любая цифра об экзамене на сайте только через `<Fact id>` со сноской на источник.
14. Прежде чем менять токены, перечитать `app/src/tokens.css`: его уже правили параллельные сессии.

## 14. Как пересъёмка делается

**Сайт (без аккаунта):**

```
cd site && npm run build
cd site && npx astro preview --port 4321 --host 127.0.0.1
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --hide-scrollbars --virtual-time-budget=8000 --window-size=1440,7200 --screenshot="C:/…/Spec/Design/screenshots/site-landing.png" http://127.0.0.1:4321/
```

Путь вывода абсолютный, с прямыми слэшами. Ширины ниже ~500 px headless Chrome на Windows не соблюдает.

**Приложение (нужна сессия):** `cd app && npx vercel dev --listen 3000 --yes` (если порт занят, Vercel возьмёт 3001; смотреть строку «Ready!»). Затем скрипт [tools/shoot-app.mjs](tools/shoot-app.mjs) на `puppeteer-core`: входит под `design-test@example.com` (пароль в переменной `SHOT_PASSWORD`; если забыт, `npm run user:create -- design-test design-test@example.com "Uczeń Test"` печатает ссылку установки пароля), перенаправляет `/fonts/*` на `/app/fonts/*`, чтобы в dev-режиме был Figtree, и снимает экраны из списка в начале файла.

```
cd <папка со скриптом> && npm i puppeteer-core
SHOT_PASSWORD=… node shoot-app.mjs http://localhost:3001 "C:/…/Spec/Design/screenshots"
```
